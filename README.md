# «Оно тебе надо»

Страница аукциона вещей, в которые никто не верил.

## Запуск

Откройте файл `index.html` в браузере.

## Структура проекта

- `index.html` — разметка страницы.
- `styles/global.css` — общие стили.
- `styles/style.css` — стили страницы.
- `fonts/` — файлы шрифта Raleway.
- `images/` — изображения и логотипы.
